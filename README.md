Financial Sales & Profitability Dashboard

Project Overview

An interactive Power BI dashboard built to analyze sales, profit, customers, regions, products, and overall business performance.

Tools Used

- Power BI
- DAX
- Power Query
- Excel
- SQL

Key KPIs

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Total Customers
- Average Order Value (AOV)

Dashboard Analysis

- Sales and Profit Performance
- Sales Growth Analysis
- Customer Analysis
- Regional Performance
- Category and Sub-Category Analysis
- Channel and Payment Method Analysis
- Profitability Analysis

Power BI Features

- KPI Cards
- Interactive Slicers
- Bar and Column Charts
- Line Charts
- Map Visual
- Treemap
- Decomposition Tree
- Key Influencers
- Waterfall Chart

Key Insights

- Identified sales and profit performance across different regions and categories.
- Compared customer and order performance.
- Analyzed factors affecting profitability.
- Identified high-performing and low-performing business segments.

Skills Demonstrated

Power BI | DAX | Power Query | Data Cleaning | Data Modeling | Data Analysis | Data Visualization
